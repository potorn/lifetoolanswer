사용방법

생활도구 각 기능의 사용방법을 안내합니다.

⚖️ BMI 계산기

  1. 키(cm)와 몸무게(kg)를 입력합니다.
  2. 계산하기 버튼을 클릭합니다.
  3. BMI 수치와 비만도 등급(저체중 / 정상 / 과체중 / 비만)을 확인합니다.
  4. 측정 날짜를 선택하고 입력한 키·몸무게 기록하기로 저장합니다. 같은 날짜의 기록은 확인 후 수정됩니다.
  5. 전체 또는 월별 기록을 선택해 체중·BMI 그래프를 확인합니다. PNG는 그래프·요약을 저장하고, PDF / 인쇄는 모든 기록표를 포함합니다. PDF는 인쇄 창에서 ‘PDF로 저장’을 선택합니다.
  6. 복원용으로 보관하려면 ‘전체 기록’에서 선택 기간 백업을 누르고 JSON 파일을 저장하세요. 백업 불러오기로 다른 브라우저에도 기록을 옮길 수 있습니다.

※ 대한비만학회 기준을 적용합니다. 결과는 참고용이며 정확한 진단은 의사와 상담하세요.

🔥 기초대사량·칼로리 계산기

  1. 성별 계수, 나이(18~100세), 키(cm), 몸무게(kg)를 입력합니다.
  2. 하루 전체 움직임에 가까운 활동량을 선택합니다.
  3. 소모 칼로리 계산하기를 눌러 휴식 시 추정치와 활동량별 하루 소모 칼로리를 확인합니다. 예시로 계산 버튼으로 사용해 볼 수도 있습니다.

※ Mifflin–St Jeor 식과 고정 활동계수의 성인 참고값입니다. 실제 측정값이나 개인별 권장 섭취량이 아닙니다.

🏃 걷기·달리기 페이스 계산기

  1. 계산할 항목(페이스·소요 시간·거리)과 거리 단위(km·마일)를 선택합니다.
  2. 선택한 항목에 따라 나머지 두 값을 입력합니다. 목표 페이스 입력은 항상 1km당 분·초 기준입니다.
  3. 계산 버튼을 눌러 페이스·속도·거리와 목표 거리별 예상 시간을 확인합니다.

※ 시간의 빈 칸은 0이며 분·초는 각각 0~59입니다. 결과는 일정한 페이스를 가정한 환산이고 입력값은 브라우저에서만 처리됩니다.

🏦 대출 이자 계산기

  1. 대출금액(만원 단위), 연 이자율(%), 대출 기간(개월)을 입력합니다.
  2. 상환 방식을 선택합니다.
    • 원리금균등 — 매달 동일한 금액을 납부
    • 원금균등 — 매달 동일한 원금 + 줄어드는 이자
    • 만기일시 — 매달 이자만 납부 후 만기에 원금 일시 상환
  3. 계산하기를 클릭하면 월 상환금, 총 이자, 상환 스케줄 표를 확인할 수 있습니다.

※ 실제 대출 상품은 중도상환수수료, 취급 수수료 등이 추가될 수 있습니다. 금융기관에 정확한 조건을 확인하세요.

📐 단위 변환기

  1. 변환할 단위 종류(길이·무게·온도·넓이·부피)를 선택합니다.
  2. 변환할 값과 원본 단위를 입력합니다.
  3. 결과란에서 모든 단위의 변환 값을 한 번에 확인합니다.

※ 넓이 변환에서 평↔m² 변환을 지원합니다.

🖼️ 이미지 포맷 변환기

  1. 변환할 이미지 파일을 업로드하거나 드래그 앤 드롭합니다.
  2. 출력 포맷(PNG·JPG·WebP·BMP·ICO·AVIF·TGA)을 선택합니다.
  3. 필요하면 리사이즈 크기를 입력합니다.
  4. 변환하기를 클릭하면 변환된 파일을 다운로드할 수 있습니다.

※ GIF와 움짤 WebP를 WebP로 변환하면 움직임을 유지합니다. GIF 출력은 GIF 만들기를 이용하세요. 업로드한 이미지는 브라우저에서 변환되며 생활도구 서버로 전송되지 않습니다.

🎨 이미지 편집기

  1. PNG·JPEG·WebP·AVIF·BMP 이미지를 선택합니다. 최대 25MB, 가로·세로 4,096px까지 지원합니다.
  2. 자르기 탭에서 자유 비율이나 1:1·4:3·16:9 등의 비율을 고르고 영역을 드래그하거나 숫자로 입력한 뒤 적용합니다.
  3. 보정 탭에서 밝기·대비·노출·색조·채도·레벨과 흑백 등의 효과를 조절합니다.
  4. 텍스트를 추가하고 글꼴·크기·색을 정합니다. 미리보기에서 드래그하거나 X·Y 위치를 입력해 옮길 수 있습니다.
  5. 저장 탭에서 PNG·JPEG·WebP와 출력 크기를 고르고 다운로드합니다.

※ 편집은 브라우저에서만 처리하며 새로고침하면 사라집니다. 자르기·회전·뒤집기는 현재 보정과 텍스트를 이미지에 합칩니다. 실행 취소는 최대 20단계이며 큰 이미지에서는 줄어듭니다. 애니메이션은 정지된 한 프레임으로 저장합니다.

🎞️ GIF 만들기

  1. 사진 여러 장 또는 짧은 동영상 모드를 선택합니다.
  2. 사진은 순서를 정하고 재생 속도와 크기를, 동영상은 시작 지점과 최대 15초 길이를 설정합니다.
  3. GIF 만들기를 누르면 변환 후 바로 다운로드할 수 있습니다.

※ 동영상은 최대 100MB, 원본 5분 이하이며 GIF에는 소리가 포함되지 않습니다. 업로드한 사진과 동영상은 브라우저에서 변환되며 생활도구 서버로 전송되지 않습니다.

💰 연봉 실수령액 계산기

  1. 연봉을 만원 단위로 입력합니다. (예: 연봉 4,000만원 → 4000 입력)
  2. 부양가족 수를 입력합니다. (본인 포함, 기본 1명)
  3. 계산하기를 클릭하면 월 실수령액과 국민연금·건강보험·소득세 등 항목별 공제 내역을 확인할 수 있습니다.

※ 2026년 4대보험 요율 기준이며 소득세는 근로소득 간이세액표 근사값입니다. 실제 수령액과 다소 차이가 있을 수 있습니다.

📊 퍼센트 계산기

  1. 계산 방식을 선택합니다.
    • 할인가 계산 — 원래 가격 + 할인율 → 할인 금액·최종 가격
    • 증감률 계산 — 변경 전·후 값 → 증감량·증감률(%)
    • 역계산 — 할인된 가격 + 할인율 → 원래 가격
  2. 선택한 방식에 맞는 값을 입력합니다.
  3. 계산하기를 클릭하면 결과를 확인합니다.

🧾 부가세 계산기

  1. 부가세 더하기 또는 합계에서 역산을 선택합니다.
  2. 공급가액 또는 부가세 포함 합계금액을 원 단위로 입력합니다.
  3. 공급가액·부가세·합계금액을 확인합니다.

✍️ 글자 수 계산기

  1. 확인할 글을 입력하거나 붙여넣습니다.
  2. 공백 포함·제외 글자 수, UTF-8 바이트, 단어 수와 줄 수를 즉시 확인합니다.

💵 예금·적금 이자 계산기

  1. 예금 또는 적금을 선택하고 금액·연 이자율·기간을 입력합니다.
  2. 예금은 단리 또는 월복리를, 공통으로 일반과세 또는 비과세를 선택합니다.
  3. 세전·세후 이자와 예상 만기금액을 확인합니다.

▦ QR 코드 생성기

  1. QR 코드에 넣을 URL이나 텍스트를 입력합니다.
  2. 오류 복원 수준과 PNG 이미지 크기를 선택합니다.
  3. QR 코드를 생성하고 PNG로 저장합니다.

※ 입력 내용과 QR 이미지는 브라우저에서 처리되며 생활도구 서버로 전송되지 않습니다.

↔️ 인코딩·디코딩

  1. Base64 또는 URL 방식을 선택합니다.
  2. 변환할 내용을 입력하고 인코딩 또는 디코딩 버튼을 누릅니다.
  3. 변환 결과를 확인하고 필요한 경우 복사합니다.

Base64·URL 인코딩 디코딩 열기

#️⃣ SHA 해시 생성기

  1. 해시값을 만들 텍스트를 입력합니다.
  2. SHA 해시 2종 생성을 누릅니다.
  3. SHA-256과 SHA-512 결과를 확인하거나 복사합니다.

※ 해시는 단방향 함수이므로 결과에서 원문을 복호화할 수 없습니다.

SHA-256·SHA-512 해시 생성기 열기

🔐 암호화·복호화

  1. AES-GCM, 키워드 암호 또는 문자 치환 방식을 선택합니다.
  2. 원문과 비밀번호·키워드·대응표 등 선택한 방식에 필요한 값을 입력합니다.
  3. 암호화 결과는 같은 방식과 키를 사용해야 다시 복호화할 수 있습니다.

※ 실제 내용 보호에는 AES-GCM을 사용하세요. 키워드와 문자 치환은 학습·놀이용입니다.

암호화·복호화 도구 열기

건강 기록·금융 조건 비교 사용방법

BMI 결과에서 키·몸무게를 기초대사량 계산기로 전달하고 소모 열량을 이미지로 저장할 수 있습니다. 페이스 계산 후에는 목표 거리의 1km 통과 시간표를 확인하고 운동 날짜·종류를 정해 기록하세요. 월별 운동 기록은 CSV·PNG로 보관하며 JSON 백업으로 복원합니다.

대출·예적금·연봉은 먼저 조건을 계산한 뒤 비교에 추가하고, 다른 조건을 다시 계산해 최대 3개를 비교하세요. 비교 결과는 첫 조건 대비 차이를 보여주며 CSV로 저장합니다. 예적금은 월별 원금·세전 이자 그래프도 제공합니다.

시스템·라이트·다크 화면 모드

상단 토글에서 화면 모드를 바꿀 수 있습니다. 기본값인 시스템은 기기 설정을 따르며, 라이트·다크를 선택하면 이 브라우저에 선택을 기억합니다. 시스템을 다시 선택하면 직접 선택한 설정을 지웁니다. 토글은 Tab으로 이동하고 방향키·Home·End로 선택할 수도 있습니다.

이미지 도구 확장 기능

이미지 포맷 변환기는 여러 장을 같은 포맷과 크기로 일괄 변환하고 용량 비교 후 ZIP으로 저장합니다. 이미지 편집기는 증명사진 비율·프로필·썸네일 프리셋과 보정·출력 설정 저장을 지원합니다. GIF 만들기에서는 목표 용량을 선택하고 실제 생성 결과의 용량과 화질을 비교할 수 있습니다. 목표 용량 초과 시 사진 수 또는 GIF 길이를 더 줄여 주세요.
