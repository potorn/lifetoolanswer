글자 수 계산기

글자 수, UTF-8 바이트, 단어 수와 줄 수를 입력 즉시 확인하세요.

입력한 글은 브라우저 안에서만 처리되며 서버로 전송되거나 저장되지 않습니다.

이모지와 결합 문자는 화면에 보이는 한 글자를 기준으로 계산합니다. 바이트는 UTF-8 기준입니다.

공백 포함 0 자
공백 제외 0 자
UTF-8 0 바이트
단어 0 개
줄 0 개

계산 방식

항목기준
공백 포함띄어쓰기와 줄바꿈을 포함한 화면상 글자 수
공백 제외띄어쓰기·탭·줄바꿈을 제외한 글자 수
UTF-8 바이트웹 전송과 저장에서 널리 사용하는 UTF-8 인코딩 기준

※ 채용·원고 제출 사이트는 줄바꿈, 한글, 이모지를 서로 다른 방식으로 셀 수 있으므로 최종 제출처의 기준을 함께 확인하세요.
