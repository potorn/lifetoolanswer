CUTOUT

배경을 걷어 내기

인물 사진의 배경을 이 브라우저에서 투명하게 만듭니다. 처음 한 번은 분리 모델과 실행 엔진을 받습니다.

사진 픽셀은 서버로 나가지 않습니다. 받는 파일은 Hugging Face CDN의 MODNet 모델(약 6.6MB)과 jsDelivr의 ONNX Runtime Web입니다. WebGPU를 쓸 수 있으면 그쪽으로, 아니면 WASM으로 계산합니다. 인물과 배경이 구분될수록 경계가 깔끔하고, 사물 사진은 가장자리가 거칠 수 있습니다.

자주 쓰는 설정 저장

보정값과 출력 포맷·품질·크기·배경색 한 세트를 저장합니다. 사진, 텍스트, 워터마크, 자르기 위치는 저장하지 않습니다. 다음 이미지에서 직접 불러오세요. 비율 유지 설정은 현재 사진을 저장 크기 안에 맞춥니다.

미리보기는 화면에 맞게 축소됩니다. 저장 시 지정한 픽셀 크기로 보정, 텍스트, 워터마크를 다시 그립니다. PNG는 투명 영역을 유지하고 JPEG는 아래 배경색으로 빈 곳을 메웁니다. 최대 4,096px · 1,600만 픽셀. GIF 제작은 GIF 만들기를 이용하세요.

Ctrl + Z 실행 취소

원본 파일은 변경되지 않습니다. 실행 취소는 최근 최대 20단계까지 지원하며, 이미지 크기에 따라 줄어듭니다.

서버 전송 없이 편집

선택한 이미지, 텍스트, 워터마크와 결과는 이 브라우저 안에서만 처리합니다. 페이지를 닫거나 새로고침하면 사진과 편집 내용이 사라지므로 다운로드해 보관하세요. 직접 저장한 보정·출력 설정은 이 브라우저에 남습니다.

배경 제거를 누르면 사진이 아니라 분리에 쓰는 파일만 받습니다. 모델은 Hugging Face CDN의 MODNet(약 6.6MB)이고, 실행 엔진은 jsDelivr의 ONNX Runtime Web입니다.

보정, 누끼, 워터마크

자유·고정 비율 크롭, 회전·뒤집기, 밝기·대비·노출·색조·채도·활기, 레벨·감마, 색 균형, 흑백·반전·세피아·포스터화·임계값, 텍스트를 지원합니다. 배경 제거 뒤에는 투명 PNG로 저장하거나 원하는 색으로 빈 곳을 채울 수 있습니다.

글자 워터마크는 크기, 색, 불투명도, 회전, 위치와 바둑판 반복을 고를 수 있고 로고 이미지도 크기와 불투명도, 위치를 정해 올릴 수 있습니다. 정밀 커브, 마스크, PSD 레이어 편집은 지원하지 않습니다. 애니메이션 GIF는 GIF 만들기, 기타 포맷은 이미지 포맷 변환기를 이용하세요.

편집기 사용 순서

  1. PNG·JPEG·WebP·AVIF·BMP 이미지를 엽니다. 자르기 탭의 크기 프리셋으로 증명사진 비율, 프로필, 썸네일 가운데를 자를 수 있습니다.
  2. 보정 탭에서 밝기와 색을 맞추고, 필요하면 텍스트를 올립니다.
  3. 배경 탭에서 배경 제거를 누릅니다. 처음에는 모델과 실행 엔진을 받으며 진행률이 표시됩니다. 끝난 뒤 색을 채워 넣거나 투명 PNG로 저장합니다.
  4. 워터마크 탭에서 문구의 크기·색·불투명도·회전·위치를 정합니다. 화면 전체에 반복하려면 바둑판 반복을 고르고, 로고는 이미지를 올려 크기와 위치를 맞춥니다.
  5. 저장 탭에서 PNG·JPEG·WebP와 출력 크기를 확인하고 다운로드합니다. 자주 쓰는 보정·출력 설정은 저장해 다음 사진에서 불러올 수 있습니다.

증명사진을 그대로 제출할 수 있나요?

413 × 531px는 증명사진 비율 참고용입니다. DPI 메타데이터나 제출 규격 준수를 보장하지 않습니다. 배경색을 채운 결과도 제출처의 픽셀 크기, 인화 크기, 배경, 얼굴 위치 조건을 따로 확인해야 합니다.

배경 제거는 어떤 사진에 잘 맞나요?

인물과 배경이 구분되는 사진에서 가장 안정적입니다. 머리카락처럼 가는 경계는 대략적으로 남고, 배경이 복잡하거나 피사체가 사물인 경우에는 가장자리가 거칠 수 있습니다. 쓰는 모델은 인물 매팅에 맞춰진 MODNet입니다. 결과가 마음에 들지 않으면 실행 취소로 바로 되돌리세요.

사진은 서버로 나가나요?

나가지 않습니다. 분리 계산은 연 브라우저 안에서 끝납니다. 기능을 처음 쓸 때만 Hugging Face CDN에서 모델 파일을, jsDelivr에서 실행 엔진을 받습니다. 그 파일에는 이용자의 사진이 들어 있지 않습니다.

워터마크는 저장 파일에도 들어가나요?

글자와 로고는 미리보기와 다운로드 파일에 같은 위치와 불투명도로 들어갑니다. 문구를 비우거나 로고를 제거하면 미리보기에서도 빠집니다. JPEG는 투명도를 담지 못하므로, 배경을 비워 둔 채 JPEG로 저장하면 저장 탭의 배경색이 빈 곳을 메웁니다.

휴대폰이나 오래된 컴퓨터에서도 되나요?

가능하면 시도합니다. 메모리가 작으면 사진을 더 줄여 계산하고, 그래픽 가속이 없으면 기본 엔진으로 바꿉니다. 받거나 계산하는 과정이 실패하면 이유를 화면에 적습니다. 그 경우에는 더 작은 이미지로 다시 시도해 주세요.

설정은 언제 사라지나요?

저장한 보정·출력 설정은 같은 브라우저에서 다시 쓸 수 있지만, 사이트 데이터 삭제나 비공개 창 종료, 다른 브라우저에서는 남지 않을 수 있습니다. 사진, 텍스트, 워터마크 문구와 로고는 설정에 저장하지 않습니다.
