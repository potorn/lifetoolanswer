개인정보처리방침

생활도구는 이용자의 개인정보를 중요하게 생각합니다.

1. 수집하는 개인정보

생활도구는 별도의 회원가입 없이 이용할 수 있으며, 이용자의 이름·이메일·연락처 등 개인 식별 정보를 수집하지 않습니다.
도구에 입력한 값과 선택한 파일은 브라우저 안에서만 처리되며 분석·광고 로그에 포함되지 않습니다. 다만 웹페이지 접속 과정에서 호스팅 사업자가 IP 주소, 브라우저 종류, 접속 시각 같은 기본 접속 정보를 처리할 수 있습니다.

  • 현재 사이트 코드에는 Google Analytics 등 별도의 이용자 분석 도구가 활성화되어 있지 않습니다.
  • Google AdSense 로더 스크립트(adsbygoogle.js)가 모든 페이지의 head에 한 번씩 들어 있습니다. 페이지 본문에는 광고 단위를 두지 않았습니다. 광고 쿠키에 관한 내용은 아래 쿠키 항목에 적었습니다.

2. 쿠키(Cookie)와 광고

Google을 포함한 제3자 공급업체는 쿠키를 사용하여, 이용자가 이 웹사이트나 다른 웹사이트를 이전에 방문한 기록을 바탕으로 광고를 게재합니다.

Google이 광고 쿠키를 사용하면 Google과 그 파트너는 이용자가 이 사이트 및 인터넷의 다른 사이트를 방문한 기록을 바탕으로 광고를 제공할 수 있습니다. 광고가 게재될 때 함께 쓰이는 공급업체는 바뀔 수 있으며, 목록과 설명은 Google 광고 기술 페이지에서 확인할 수 있습니다.

이용자는 Google 광고 설정에서 맞춤 광고를 끌 수 있습니다. 제3자 공급업체가 맞춤 광고에 쿠키를 사용하는 것을 거부하려면 www.aboutads.info의 안내를 이용할 수도 있습니다. 브라우저에서 쿠키를 끄면 사이트 일부 기능이 제한될 수 있습니다.

3. 개인정보의 이용 목적

사이트 운영 과정에서 처리되는 기본 접속 정보는 서비스 제공, 보안, 장애 대응 및 통계 확인 목적으로만 사용합니다. 도구 입력값과 업로드 파일은 수집하거나 서버에 저장하지 않습니다.

4. 도구 입력값과 업로드 파일의 처리

BMI·대출·부가세·예금·적금 계산기와 글자 수·QR 코드 도구에 입력하는 값, 이미지 변환기·이미지 편집기·GIF 만들기에 업로드하는 이미지·동영상은 이용자의 브라우저에서 처리됩니다. 해당 입력값과 파일은 생활도구 서버로 전송되거나 저장되지 않습니다. 이미지 편집기의 배경 제거도 사진을 서버로 보내지 않고 브라우저에서 계산합니다. 그 기능을 켜면 분리 모델 파일(MODNet, 약 6.6MB)을 Hugging Face CDN에서, 실행 엔진(ONNX Runtime Web)을 jsDelivr에서 내려받습니다. 내려받는 파일에는 이용자의 사진이 포함되지 않습니다.
BMI 계산기에서 기록 저장을 선택하면 측정 날짜·키·몸무게가 현재 브라우저의 로컬 저장소(localStorage)에 보관됩니다. 이 기록은 서버로 전송되지 않으며 기기·브라우저 간 동기화되지 않습니다. 기록별 삭제 또는 브라우저의 해당 사이트 데이터 삭제로 지울 수 있습니다. 시크릿 모드 종료나 사이트 데이터 삭제 시 기록이 사라질 수 있으므로 필요한 기록은 백업 파일로 보관하세요. PNG·PDF·JSON 내보내기 파일은 이용자가 선택한 기기에 저장됩니다.

5. 방침의 변경

본 개인정보처리방침은 법령 또는 서비스 변경에 따라 업데이트될 수 있습니다. 변경 시 본 페이지를 통해 공지합니다.

최종 업데이트: 2026년 11월 24일

운동 기록과 도구 간 정보 전달

걷기·달리기 기록 저장을 선택하면 운동 날짜·종류·거리·시간과 기록 ID가 현재 브라우저의 localStorage에 보관됩니다. 개별 기록 삭제 또는 사이트 데이터 삭제로 지울 수 있으며, 다른 기기와 동기화되지 않습니다. 기록은 생활도구 서버로 전송되지 않습니다. 필요한 기록은 JSON으로 백업하세요.

BMI의 칼로리 계산 링크를 선택하면 키·몸무게와 전달 시각을 같은 탭의 sessionStorage에 잠시 보관하고 기초대사량 페이지에서 읽은 뒤 삭제합니다. 5분이 지난 전달값은 적용하지 않습니다. URL에는 신체 정보를 넣지 않습니다. 대출·예적금·연봉 비교 조건은 현재 페이지 메모리에서만 유지됩니다. 사용자가 내보낸 PNG·CSV·JSON 파일은 이용자가 보관하고 관리합니다.

화면 모드 설정의 보관

처음 방문하면 기기의 시스템 화면 설정을 따릅니다. 라이트·다크 모드를 직접 선택하면 해당 선택값만 이 브라우저의 localStorage에 저장해 다음 방문에도 적용합니다. 시스템을 선택하면 저장한 화면 모드 설정을 삭제합니다. 이 설정은 서버로 전송되지 않습니다.

이미지 편집 설정 저장

이미지 편집기에서 설정 저장을 누르면 보정값과 출력 포맷·품질·크기·배경색을 이 브라우저의 localStorage에 저장합니다. 사진, 텍스트, 워터마크 문구·로고, 자르기 위치는 저장하지 않습니다. 저장한 설정 삭제 버튼 또는 브라우저의 사이트 데이터 삭제로 지울 수 있습니다. 일괄 변환 파일과 GIF 비교 결과는 서버로 전송하지 않으며 페이지를 닫으면 사라집니다.

배경 제거 모델의 내려받기

이미지 편집기에서 배경 제거를 누르면, 사진을 계산하기 위한 모델 파일과 실행 엔진을 이용자의 브라우저가 직접 받습니다. 모델은 MODNet 양자화 ONNX 파일(약 6.6MB, Apache-2.0)이며 Hugging Face CDN(cdn.hf.co를 포함한 huggingface.co)에서 내려받습니다. 실행 엔진은 ONNX Runtime Web 1.22.0(MIT)이며 jsDelivr(cdn.jsdelivr.net)에서 내려받습니다. 사진 데이터는 이 요청에 실리지 않고, 받은 파일은 그 브라우저의 캐시에 남아 다음 실행을 줄일 수 있습니다. 사이트 데이터를 지우면 캐시도 함께 지워집니다.
