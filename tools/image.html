이미지 일괄 변환 사용법

  1. 일괄 변환 영역에서 파일을 여러 장 선택합니다.
  2. 출력 포맷과 최대 크기를 정하고 일괄 변환을 누릅니다.
  3. 각 파일의 용량을 비교하고 성공한 결과를 ZIP 또는 개별 파일로 저장합니다.

ZIP은 이미 압축된 이미지들을 묶는 용도입니다. ZIP 자체가 이미지 용량을 더 줄이지는 않습니다. 이름이 같아도 순번을 붙여 덮어쓰기를 피합니다.

이미지 포맷별 특징

포맷특징
PNG무손실·투명도 지원. 그래픽과 캡처 이미지에 적합합니다.
JPEG사진에 적합한 손실 압축 형식입니다. 투명도는 지원하지 않습니다.
WebP작은 파일 크기와 투명도·애니메이션을 함께 지원합니다.
AVIF높은 압축 효율을 제공하는 최신 이미지 형식입니다.
BMP · ICO · TGAWindows 비트맵, 파비콘, 게임·3D 작업에 쓰이는 형식입니다.

GIF 출력은 GIF 만들기에서, 크롭·색상 보정·텍스트 삽입은 이미지 편집기에서 이용하세요.

자주 묻는 질문

일괄 변환에서 일부 파일이 실패하면 어떻게 되나요?

나머지 파일은 계속 처리합니다. 오류 사유를 확인한 뒤 성공한 파일만 ZIP으로 저장할 수 있습니다. 변환 결과가 원본보다 커질 수 있으므로 전후 용량을 확인하세요.

GIF 출력과 애니메이션은 어떻게 이용하나요?

GIF 출력은 별도 GIF 만들기를 이용하세요. 이 변환기는 GIF 입력을 지원하며 애니메이션 GIF와 WebP를 WebP로 저장하면 움직임을 유지합니다. PNG·JPEG·BMP·ICO·TGA·AVIF로 저장하면 첫 프레임만 저장됩니다.

이미지 파일은 어디로 전송되나요?

업로드한 파일은 생활도구 서버로 전송하거나 저장하지 않습니다. 이 페이지에서 실행되는 이미지 처리 엔진이 브라우저에서 변환합니다.
