사진과 동영상으로 GIF 만드는 방법

  1. 사진 여러 장 또는 짧은 동영상을 선택합니다.
  2. 사진은 순서를 드래그해 바꾸고, 동영상은 시작 지점과 길이를 정합니다.
  3. 목표 용량을 선택하고 GIF 만들기를 누릅니다. 자동 조절을 끄면 원래 설정으로만 생성합니다.
  4. 실제 생성된 크기·프레임·용량과 움직임을 비교한 뒤 원하는 결과를 선택해 다운로드합니다.

자주 묻는 질문

사진 파일과 동영상은 서버로 전송되나요?

아니요. 업로드 파일은 브라우저에서 처리되며 생활도구 서버로 전송하거나 저장하지 않습니다. 변환 중 페이지를 닫으면 작업도 함께 종료됩니다.

목표 용량이 보장되나요?

아니요. 이미지 내용과 움직임에 따라 용량이 달라집니다. 처리 전 확정 용량 대신 생성 후 실제 용량을 표시하며, 목표를 충족하지 못하면 초과 상태를 안내합니다. 크기·프레임을 줄이면 선명도와 움직임이 달라집니다.

동영상 GIF가 너무 큰 경우 어떻게 하나요?

목표 용량을 선택하면 최대 4단계로 크기·프레임을 줄여 실제 생성 용량을 비교합니다. 목표 초과가 표시되면 사진 수나 GIF 길이를 줄여 다시 만들어 주세요. 저장 가능한 결과는 15MB 이하입니다.
